Meshtastic CYD Keyboard v2.1

ESP32-2432S028R (2.8" Cheap Yellow Display) -> Heltec V3 Terminal

1-Click Flash

Connect CYD via USB, use Chrome/Edge

If no binary yet, build via GitHub Action below

Wiring

Heltec V3              CYD 2.8"
-------------------------------
GPIO 6 (TX1)  ----->  GPIO 22 (RX2)
GPIO 7 (RX1)  <-----  GPIO 27 (TX2)
GND           ------  GND
5V            ------  5V

Enable on Heltec:
meshtastic --set serial.enabled true
meshtastic --set serial.txd 6
meshtastic --set serial.rxd 7
meshtastic --set serial.baud 115200
meshtastic --set serial.mode TEXTMSG

Features v2.1 + Channel Swap

  • Splash screen with boot progress
  • 4-point calibration saved to NVS - hold top-left on boot to redo
  • Tap CH bar to open channel selector (8 channels: LongFast etc)
  • Or type /ch0 to /ch7 + SEND to quick swap
  • 14-line message log, QWERTY with SHIFT/123, SPACE, DEL, SEND
  • Status bar: MESH / CH name / LINK dot

GitHub Action Build

1. Create repo github.com/YOURNAME/meshtastic-cyd-keyboard
2. Upload all files from this project
3. GitHub -> Actions -> Build CYD Keyboard Firmware -> Run
4. After 3 min, download artifact: cyd-keyboard-v2.1-factory.bin
5. Put .bin in same folder as this HTML, flash!

Or local: pio run -e esp32-2432s028r then esptool.py write_flash 0x0 .pio/build/.../firmware.factory.bin
